## Runtime mapping

These PNG files are the canonical source artwork. `src/shared/Branding/Branding.luau`
owns every runtime reference. Official Roblox asset IDs are the primary runtime
source, while matching `rbxgameasset` image names provide a development fallback.
UI controllers must not contain branding IDs or repository paths.
